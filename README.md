# Cover Letter Generator

A Streamlit-based AI cover letter generator that creates personalized cover letters using OpenAI's GPT.

## Features

- Input your resume, job requirements, and company facts
- AI-powered cover letter generation
- Edit generated content before downloading
- Export as PDF or text file

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the app:
```bash
streamlit run app.py
```

3. Enter your OpenAI API key in the sidebar

## Deployment on Streamlit Cloud

1. Push this repo to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo and deploy

## Requirements

- Python 3.8+
- OpenAI API key
